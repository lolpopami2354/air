# KPHX Full Airport & TRACON Radar Simulator (v3)

## New Features in v3
1. **TRACON Radar & Ground/Tower View Switcher:**
   - Use the top header tabs (**TRACON RADAR** and **GROUND & TOWER**) to switch between the 35 NM approach scope and zoomed-in airport surface operations.
2. **3-Runway Airport Layout:**
   - Manage arrivals and departures across **Runway 26** (North), **Runway 25R** (Center), and **Runway 25L** (South), plus Terminal Gates A1-B2.
3. **Slow-Paced Start:**
   - Starts with a single aircraft and spaces new traffic out every 28–42 seconds so you never get overwhelmed right away.
4. **1-in-25 Random Emergencies:**
   - Every arriving aircraft has a 1-in-25 (4%) chance of declaring a Mayday emergency (engine flameout, low fuel, pressurization, or hydraulic failure) for a **+300 pt** priority landing bonus.

## How to Run (Permanent Mic Permission)
- Double-click `start-server.bat` on Windows (or run `python -m http.server 8000` in this folder) and open `http://localhost:8000` in Chrome or Edge so your browser remembers your microphone permission permanently.
